# Germany Participant Guide

## Germany থেকে NASA Space Apps Challenge-এ অংশগ্রহণের প্রস্তুতি

> **এটি Germany-তে থাকা participant-দের জন্য ব্যবহারিক সহায়ক গাইড—NASA-র official policy বা কোনো নির্দিষ্ট বছরের event announcement নয়।** Germany-তে কোনো Local Event হবে, কোন শহরে হবে, onsite/online format কী হবে, registration বা team rules কী—এসব প্রতি বছরের official event listing ও সংশ্লিষ্ট Local Event page-এ যাচাই করতে হবে। Listing-এ না দেখে কোনো city/event-কে official বলা যাবে না।
>
> সময়সূচি, eligibility, team size, challenge-work window, submission deadline, judging, AI/SI use, consent ও licence-এর ক্ষেত্রে আপনার অংশগ্রহণের বছরের [Participant FAQs](https://www.spaceappschallenge.org/resources/participant-faqs/), [Participant Terms and Conditions](https://www.spaceappschallenge.org/legal/), event page এবং Participant Guides-ই চূড়ান্ত।

## Germany-তে বিশ্ববিদ্যালয়ে পড়া বন্ধুর জন্য সংক্ষিপ্ত উত্তর

হ্যাঁ—Germany-তে university student হওয়া নিজে থেকে NASA Space Apps Challenge-এ অংশ নেওয়ার বাধা নয়। তবে student হওয়া অংশগ্রহণের eligibility নিশ্চিতও করে না। তাঁর বয়স, residence/citizenship-সংক্রান্ত শর্ত (যদি থাকে), event affiliation, registration, team ও submission rules অংশগ্রহণের বছরের official FAQ, Terms এবং event page-এ যাচাই করতে হবে।

Germany-তে থাকা international student-ও একই নিয়মে official eligibility যাচাই করবেন; German university-তে পড়েন বলে German citizenship বা Germany-র Local Event-এ স্বয়ংক্রিয় registration হয়ে যায় না। কোনো Local Event বা virtual option বেছে নেওয়ার আগে current-year listing এবং account-এর event status দেখুন।

বন্ধুকে পাঠানোর জন্য:

```text
Germany-তে university student হওয়া NASA Space Apps Challenge-এ অংশ নেওয়ার
নিজস্ব বাধা নয়; তবে তোমার বয়স/eligibility, registration, event affiliation
ও team rules current-year official FAQ এবং Terms-এ মিলিয়ে নিও। Official
event listing-এ Germany-র Local Event আছে কি না দেখো। না থাকলে সেই বছরের
অনুমোদিত virtual option ও eligibility যাচাই করো। Deadline `Europe/Berlin`
timezone-এ লিখে রাখবে—CET/CEST বদলের কারণে event date-সহ conversion করবে।
```

```text
অংশগ্রহণের বছর ও official event page খুঁজুন

        ↓

        ↓

        ↓
একই event-এ অংশ নেওয়া teammate খুঁজুন ও team rules যাচাই করুন
        ↓
Challenge, data access, online coordination ও task plan প্রস্তুত করুন
        ↓
Event window-তে project, demo ও submission সম্পন্ন করুন
```

### মনে রাখুন

- Germany-তে আগের বছর event হয়েছিল—এ কারণে এ বছরও হবে ধরে নেবেন না।
- Official event listing-এ না থাকলে social-media poster বা পুরোনো blog-কে registration confirmation ভাববেন না।
- “Online event” মানেই deadline, team eligibility বা judging-এর নিয়ম শিথিল—এমন নয়।
- Event-এর start/end ও deadline **তারিখ + সময় + timezone**-সহ লিখুন।
- Germany-র সময় বছরের এক অংশে CET, অন্য অংশে CEST হয়; deadline-এ fixed UTC offset ধরে নেবেন না।
- Germany-তে থাকা মানেই কোনো নির্দিষ্ট Local Event বা Universal Event-এর জন্য স্বয়ংক্রিয় eligibility—এমন নয়; current rules পড়ুন।

## ২. Germany-তে Local Event যাচাই

### ২.১ Official listing-এ খোঁজার ধাপ

1. [NASA Space Apps official website](https://www.spaceappschallenge.org/) খুলে সঠিক বছরের event page খুঁজুন।
2. Event finder/listing-এ Germany এবং আপনার শহর/অঞ্চল দিয়ে search করুন।
3. Event page-এ Local Event-এর exact name, date, format, venue/online access, Local Lead/contact ও registration status দেখুন।
4. Event-টি current edition-এর কিনা যাচাই করুন; পুরোনো year-এর page বা search-engine cached result নয়।
5. Registration/login-এর পরে account বা participant dashboard-এ event affiliation/status মিলিয়ে নিন।
6. Venue/event organizer-এর ঘোষণার সঙ্গে official listing-এর তথ্য না মিললে Local Lead-কে official contact দিয়ে জিজ্ঞেস করুন।

### ২.২ Event সত্যতা যাচাইয়ের তালিকা

- [ ] Page-টি `spaceappschallenge.org`-এর official domain-এ অথবা official site থেকে link করা।
- [ ] Event-এর year ও date বর্তমান edition-এর সঙ্গে মেলে।
- [ ] Exact Local Event name ও organizer/Local Lead শনাক্ত করা যায়।
- [ ] Onsite/virtual/hybrid format স্পষ্ট।
- [ ] Venue address বা online participation-এর নির্দেশনা দেওয়া আছে।
- [ ] Registration link official page থেকে পাওয়া।
- [ ] Contact method event page বা official support page-এ আছে।
- [ ] কোনো fee, ID বা ব্যক্তিগত তথ্য চাইলে তার কারণ ও official policy যাচাই করা হয়েছে।

> কোনো listing না পাওয়া গেলে, তার অর্থ এই নয় যে Germany থেকে অংশ নেওয়া যাবে না। Current-year website-এ Universal Event বা অন্য অনুমোদিত participation option আছে কি না দেখুন। যোগ্যতা ও team affiliation-এর শর্ত আলাদা করে পড়ুন।

### ২.৩ Local Event সম্পর্কে কী প্রশ্ন করবেন

Local Lead বা official contact-কে প্রয়োজনমতো জিজ্ঞেস করুন:

- Event onsite, virtual, নাকি hybrid?
- Onsite হলে venue, entry/check-in, opening hours ও accessibility arrangement কী?
- Event-এর official timezone কোনটি এবং local schedule কোথায় update হবে?
- Internet, Wi-Fi, power outlet ও charging-এর ব্যবস্থা আছে কি?
- Participant-কে laptop, adapter, food বা অন্য কিছু আনতে হবে কি?
- বয়স/guardian, photography, recording বা consent-এর কোনো local instruction আছে কি?
- Local judging, Global Judging eligibility ও submission deadline-এর পার্থক্য কী?
- Schedule/venue বদলালে কোন official channel-এ জানানো হবে?
- Venue-এ প্রবেশ, public transport বা accessibility বিষয়ে স্থানীয় কী নির্দেশনা মানতে হবে?

## ৩. Germany সময় (Europe/Berlin) ও deadline

Germany-র event planning-এর জন্য `Europe/Berlin` timezone ব্যবহার করুন। Germany-তে সাধারণত:

- **CET (Central European Time): UTC+01:00**
- **CEST (Central European Summer Time): UTC+02:00**

Daylight-saving পরিবর্তনের কারণে একই local clock time বছরের ভিন্ন তারিখে ভিন্ন UTC offset হতে পারে। তাই `UTC+01:00` বা `UTC+02:00` স্থায়ী ধরে রূপান্তর করবেন না—event date-সহ `Europe/Berlin` নির্বাচন করুন। Germany-তে বসবাস করলেও আপনার event, Local Event বা submission page অন্য timezone ব্যবহার করতে পারে।

### ৩.১ Time conversion workflow

```text
Official date + time + stated timezone:
Germany-র local time (Europe/Berlin):
Calendar entry-এর timezone:
Deadline থেকে team-এর internal cutoff:
যাচাইয়ের তারিখ:
```

1. Source-এ timezone লেখা আছে কি না দেখুন—যেমন `UTC`, `EDT`, `PDT` বা event-এর নিজস্ব timezone।
2. Event-এর নির্দিষ্ট date-সহ calendar বা time converter-এ `Europe/Berlin` নির্বাচন করুন।
3. Conversion-এর পরে date-ও মিলিয়ে নিন; Germany-তে deadline আগের/পরের calendar date-এ পড়তে পারে।
4. Summer-time change-এর কাছাকাছি তারিখ হলে event page-এর displayed time ও timezone পুনরায় নিশ্চিত করুন।
5. একজন submission owner ও একজন checker—দুজনের calendar-এ একই deadline আছে কি না দেখুন।
6. Official source update হলে event facts ও reminder সংশোধন করুন।
7. Team-এর internal submission cutoff official deadline-এর আগে রাখুন—upload বা portal সমস্যা সামলানোর সময় পেতে।

**উদাহরণ template—সময় official event page দেখে পূরণ করুন:**

```text
Official deadline: [YYYY-MM-DD, HH:MM, timezone]
Germany local time: [YYYY-MM-DD, HH:MM, Europe/Berlin]
Team cutoff:       [local time; official deadline-এর আগে]
Confirmed by:      [নাম/তারিখ]
```

সময় আন্দাজে রূপান্তর করবেন না। Calendar event-এ timezone হিসেবে `Europe/Berlin` রাখুন; শুধু “Germany time” লিখে থেমে যাবেন না।

## ৪. Registration ও account প্রস্তুতি

- শুধু official website বা official event page থেকে registration শুরু করুন।
- সঠিক year, event name ও participation format বেছে নিয়েছেন কি না double-check করুন।
- Account confirmation, participant dashboard এবং team/event status দেখুন।
- Registration deadline, event start, project submission deadline ও timezone আলাদা করে নথিবদ্ধ করুন।
- Password, one-time code, recovery code বা API credential teammate-সহ কাউকেই দেবেন না।
- Public profile, team chat বা open repository-তে অপ্রয়োজনীয় phone number, home address, identity document বা ব্যক্তিগত নথি দেবেন না।
- বয়স, guardian consent বা media consent লাগতে পারে কি না current Terms ও event page থেকে যাচাই করুন।
- Registration error হলে screenshot-এ password/token আড়াল করুন এবং official support/contact-এ জানান।
- Account-এ multi-factor authentication থাকলে ব্যবহার করুন এবং recovery option নিজের নিয়ন্ত্রণে রাখুন।

Registration-এর পরে event বা team বদলানো যাবে কি না current rules-এ যাচাই করুন। Duplicate account বা duplicate team তৈরি করে সমস্যার সমাধান করার চেষ্টা করবেন না, যদি official support তা না বলে।

## ৫. Germany থেকে teammate খোঁজা ও team তৈরি

### ৫.১ Teammate খোঁজার জায়গা

প্রথমে ব্যবহার করুন:

- Official participant platform বা team-finding feature, যদি current edition-এ থাকে;
- আপনার Local Event-এর official page/Local Lead;
- Universal Event-এর official participant space, যদি আপনার জন্য প্রযোজ্য হয়;
- Event organizer কর্তৃক অনুমোদিত community/channel;
- পরিচিত university, school, research, developer, design বা data community—তবে event-এ যোগদানের জন্য official registration আলাদাভাবে সম্পন্ন করুন।

কোনো community-এর নাম, logo বা social post দেখে তাকে official partner ধরে নেবেন না; official event page থেকে cross-check করুন।

### ৫.২ Team fit-এ যা মিলিয়ে দেখবেন

| বিষয় | আগে আলোচনা করুন |
|---|---|
| Event affiliation | সবাই একই event/team-এর যোগ্য কি না—current rules দেখে |
| Availability | কোন দিন/সময় কাজ করতে পারবেন; কাজ, পড়াশোনা বা অন্য দায়িত্ব আছে কি না |
| Timezone | Germany-র `Europe/Berlin` ও অন্য সদস্যের timezone; shared meeting slot |
| Skill/interest | Research, data, coding, mapping, design, writing, testing, demo |
| Internet/device | Online meeting, data access ও demo চালানোর সক্ষমতা |
| Language | Team planning language এবং final submission-এর ভাষা |
| Responsibility | Task owner, backup, submission owner ও independent checker |
| Safety/privacy | যোগাযোগের নিরাপদ channel, public profile ও personal data সীমা |

### ৫.৪ Team limit ও eligibility

Team size, member-দের একই Local Event/Universal Event-এ থাকা, একজনের একাধিক team-এ অংশগ্রহণ, একটি team-এর challenge সংখ্যা এবং Global Judging-এর minimum member—সবই current-year rule দিয়ে যাচাই করুন। আগের বছরের সংখ্যাকে স্থায়ী নিয়ম ভাববেন না।

> **২০২৬ সালে যাচাইকৃত:** ২০২৬ FAQ-তে সর্বোচ্চ ৬ জনের team, একজনের এক team-এ থাকা, এক team-এর এক challenge এবং Local/Universal Event অনুযায়ী Global Judging-এর আলাদা minimum উল্লেখ ছিল। ২০২৭ বা অন্য বছরের eligibility হিসেবে এগুলো ব্যবহার করার আগে নতুন FAQ ও guide দেখুন।

## ৬. Internet, বিদ্যুৎ ও device প্রস্তুতি

### ৬.১ Internet ও online collaboration check

Event-এর আগে এবং শুরুতে:

- Primary internet connection-এ official site, project repository, required API এবং demo link খোলা যায় কি না পরীক্ষা করুন।
- Video call-এর পাশাপাশি audio/text-based fallback channel ঠিক করুন।
- বড় dataset, package বা video transfer-এর প্রয়োজন হলে access, download size, time ও licence আগে যাচাই করুন।
- Authentication, API key, rate limit, data download size এবং account access পরীক্ষা করুন।
- Shared link reviewer-এর account ছাড়াই খোলা যায় কি না, private data না দেখিয়ে পরীক্ষা করুন।
- Internet provider বা service সমস্যার সম্ভাবনায় প্রয়োজনীয় document, task list ও source register-এর নিরাপদ offline copy রাখুন।

### ৬.২ Low-bandwidth কাজের পদ্ধতি

- Video বন্ধ রেখে audio বা text update ব্যবহার করুন, যদি team ও event format অনুমতি দেয়।
- বড় file বারবার upload না করে version control-এ প্রয়োজনীয় code/document ভাগ করুন।
- কাজের handoff লিখুন: কী হয়েছে, কোন file/commit, কীভাবে চালাতে হবে, পরবর্তী কাজ কী।
- Demo-র local copy, screenshot বা short recording রাখুন—তবে এগুলো live demo বা official submission-এর বিকল্প নয়।
- Critical page/API না চললে offline sample বা static output দেখান; mock/synthetic data হলে স্পষ্ট label দিন।
- আগে থেকে data download করলে সেটি event rules, provider terms ও data licence অনুযায়ী অনুমোদিত কি না নিশ্চিত করুন।

### ৬.৩ বিদ্যুৎ ও device contingency

- Laptop/phone charge, charger, প্রয়োজনীয় adapter এবং power-saving settings পরীক্ষা করুন।
- Onsite event হলে power outlet আছে ধরে নেবেন না; organizer-কে জিজ্ঞেস করুন।
- Shared device ব্যবহার করলে আলাদা account/profile, screen lock ও logout-এর ব্যবস্থা রাখুন।
- কাজের file নিয়মিত remote repository বা অনুমোদিত backup-এ রাখুন; secret/key commit করবেন না।
- বিদ্যুৎ/connection ব্যর্থ হলে কোন task offline করা যাবে তার তালিকা রাখুন—যেমন writing, source register, demo script, storyboard বা test plan।
- নিরাপত্তাহীন electrical setup, অতিরিক্ত গরম device বা ঝুঁকিপূর্ণ charging এড়িয়ে চলুন।

## ৭. Germany-তে onsite event-এ যাওয়ার প্রস্তুতি

এই অংশ শুধু তখন প্রযোজ্য, যখন current-year official listing-এ আপনার জন্য onsite Local Event নিশ্চিত করা আছে।

- Venue address ও map official event page/organizer-এর মাধ্যমে নিশ্চিত করুন।
- Check-in time, entry requirement, age/guardian policy, venue opening/closing time জেনে নিন।
- যাতায়াত, ফেরার ব্যবস্থা, accessibility এবং event-এর দিনে সম্ভাব্য public-transport/service update নিজে যাচাই করুন।
- খাবার, পানি, medication ও accessibility need কীভাবে সামলাবেন তা organizer-কে জিজ্ঞেস করুন।
- Laptop, charger, adapter, headphones ও প্রয়োজনীয় stationery নিন—কিন্তু venue নির্দেশনার বাইরে দামী/অপ্রয়োজনীয় জিনিস আনবেন না।
- অন্য participant-এর ছবি/কণ্ঠ record বা public করার আগে consent ও event photo policy মানুন।
- Venue/organizer-এর নির্দেশনা বদলালে official channel থেকে নতুন তথ্য নিশ্চিত করুন।
- ভ্রমণ, insurance, visa/residence status বা কাজ/পড়াশোনার অনুমতি-সংক্রান্ত ব্যক্তিগত প্রশ্নে সংশ্লিষ্ট official authority বা qualified adviser-এর নির্দেশনা নিন; এই গাইড আইনি/immigration advice নয়।

## ৮. Privacy, account ও project data

- Team-এর প্রয়োজন নেই এমন personal data সংগ্রহ বা share করবেন না।
- Participant, minor, user বা অন্য identifiable ব্যক্তির ছবি, voice, name ও location প্রকাশের আগে current Terms, consent এবং প্রযোজ্য privacy requirement যাচাই করুন।
- Public repo-তে password, API key, access token, private dataset বা ব্যক্তিগত নথি রাখবেন না।
- Project-এ user input সংগ্রহ করলে কী সংগ্রহ, কেন, কোথায় রাখা, কে access পাবে এবং কীভাবে delete করা হবে—সেটি README-তে ব্যাখ্যা করুন।
- Germany বা অন্য EU দেশে প্রযোজ্য privacy/data-protection obligation থাকতে পারে; project-এর data handling নিয়ে সন্দেহ হলে qualified guidance নিন। এই document আইনি পরামর্শ নয়।
- Data প্রকাশের অধিকার, licence ও attribution আলাদা করে যাচাই করুন; public link মানেই unrestricted reuse নয়।

## ৯. Challenge বাছাই: Germany context-এ feasibility

Germany বা ইউরোপ-সম্পর্কিত কোনো problem নিয়ে কাজ করলেই dataset সেখানকার জন্য যথেষ্ট নির্ভুল—এমন নয়। Challenge-এর scope ও data coverage যাচাই করুন।

### Data feasibility-র প্রশ্ন

- Dataset কি Germany বা নির্দিষ্ট region কভার করে?
- Spatial resolution ও temporal coverage আপনার প্রশ্নের জন্য যথেষ্ট?
- Measurement unit, quality flag, missing value, processing level বোঝা হয়েছে?
- Dataset-এর update latency এবং API availability কী?
- Administrative boundary, coordinate reference system বা local time data-র সঙ্গে মেলে?
- Ground validation বা স্থানীয় contextual knowledge আছে কি?
- Result-এর uncertainty ও limitation কীভাবে user-কে জানাবেন?
- Public-facing map/claim মানুষের privacy, safety বা sensitive location ঝুঁকিতে ফেলতে পারে কি?

একটি satellite pixel, model estimate বা correlation-কে নিশ্চিত ground truth/কারণ হিসেবে উপস্থাপন করবেন না। Data coverage না থাকলে Germany-সম্পর্কিত ফল বলে দাবি করবেন না; mock/synthetic data হলে তা স্পষ্টভাবে label করুন।

## ১০. ভাষা, demo ও team communication

- Team-এর কাজের ভাষা আগে ঠিক করুন; সদস্যদের বোঝার সুবিধা ও সময় বিবেচনা করুন।
- International team হলে প্রতিটি meeting time-এ `Europe/Berlin` বা সংশ্লিষ্ট timezone লিখুন; শুধু “সকাল ৯টা” লিখবেন না।
- Presentation বা video-তে pronunciation, caption/subtitle এবং readable text পরীক্ষা করুন।
- German, English বা অন্য ভাষার interface হলে target audience কারা, তা project-এ স্পষ্ট করুন।
- Live demo-তে internet dependency থাকলে তা আগে জানিয়ে local/offline fallback প্রস্তুত রাখুন।
- Project-এর impact Germany-তে প্রযোজ্য বলে দাবি করলে evidence, geography ও limitation উল্লেখ করুন।
- NASA/partner agency-র endorsement আছে বলে দেখাবেন না, যদি official authorization না থাকে।

## ১১. সমস্যা হলে যোগাযোগ ও escalation

| সমস্যা | প্রথম পদক্ষেপ |
|---|---|
| Official event listing খুঁজে পাচ্ছেন না | Official event finder/resource page-এ year ও region দিয়ে খুঁজুন; official contact-এ জিজ্ঞেস করুন |
| Registration/account error | Error text ও time নোট করুন; password/token আড়াল করে official support-এ জানান |
| Local Event-এর তথ্য অমিল | Official listing ও Local Lead—দু’দিকে লিখিতভাবে নিশ্চিত করুন |
| Universal Event eligibility অস্পষ্ট | Current FAQ/Terms এবং participant guide দেখুন; GO Team support-এ প্রশ্ন পাঠান |
| Team member অনুপস্থিত | Handoff note ও backup owner ব্যবহার করুন; scope কমান |
| Internet/API unavailable | Local fallback/demo artifact ব্যবহার; data/mock status সত্যভাবে জানান |
| Deadline/timezone নিয়ে সন্দেহ | Official event page পুনরায় দেখুন; Germany-র জন্য `Europe/Berlin` ব্যবহার করে conversion যাচাই করুন |
| Safety/harassment | Current Code of Conduct ও event reporting channel অনুসরণ করুন; onsite জরুরি ঝুঁকিতে venue staff/local emergency support নিন |
| Payment/fee বা অস্বাভাবিক তথ্যের অনুরোধ | Official event page-এ যাচাই না করে অর্থ/সংবেদনশীল তথ্য দেবেন না |

কোনো event বা support contact-কে message করার সময় event name/year, account email (শুধু official support-এ), local time ও timezone, সমস্যা, error text এবং ইতিমধ্যে চেষ্টা করা ধাপ লিখুন। Password, one-time code বা API secret পাঠাবেন না।

## ১২. Germany থেকে অংশগ্রহণকারীর FAQ

### Germany-তে university student হলে কি অংশ নেওয়া যায়?

সাধারণভাবে student হওয়া নিজে থেকে বাধা নয়। কিন্তু বয়স, eligibility, event registration ও team rules current-year Terms/FAQ থেকে যাচাই করতে হবে। এটি নির্দিষ্ট ব্যক্তির eligibility-এর নিশ্চয়তা নয়।

### Germany-তে থাকা international student কি অংশ নিতে পারেন?

তাঁর nationality বা residence status নিয়ে বিশেষ শর্ত আছে কি না current-year Terms ও registration page-এ দেখুন। Germany-তে university-তে পড়া মানেই Local Event-এ স্বয়ংক্রিয় eligibility বা registration নয়।

### Germany-তে Local Event না পেলে কি অংশ নেওয়া যাবে না?

এমন সিদ্ধান্তে পৌঁছাবেন না। Current edition-এ Universal Event বা অন্য অনুমোদিত participation option আছে কি না official website ও FAQ-তে দেখুন। Eligibility, event affiliation ও judging-এর নিয়ম মানতে হবে।

### Germany থেকে Universal Event-এ register করা যাবে?

এটি অংশগ্রহণের বছরের eligibility ও event setup-এর ওপর নির্ভর করে। Current FAQ, registration page ও Terms-এ নিশ্চিত না হয়ে ধরে নেবেন না।

### Germany-র সময় কি event-এর সময়ের সঙ্গে এক?

সবসময় নয়। Event page-এর timezone থেকে `Europe/Berlin`-এ রূপান্তর করুন। CET/CEST পরিবর্তনের কারণে event date-সহ conversion যাচাই করুন।

### Internet ধীর বা সাময়িকভাবে বন্ধ হলে কী করব?

Team coordination-এর text/audio fallback, local project copy, offline task ও demo artifact প্রস্তুত রাখুন। Official registration ও submission requirement পূরণ করতে হবে; fallback artifact-কে submission complete ধরে নেবেন না।

### German ভাষায় project জমা দেওয়া যাবে?

Submission language ও field requirement current-year guide-এ যাচাই করুন। German ব্যবহার করলে international reviewers-এর জন্য প্রয়োজনমতো English summary, subtitle বা translation যোগ করা সহায়ক হতে পারে; এটিকে official requirement ধরে নেবেন না।

### Team কি শুধু Germany-র সদস্যদের নিয়ে হতে হবে?

Team composition ও event affiliation-এর নিয়ম current FAQ-তে দেখুন। একই Local Event/Universal Event-এ থাকা, সদস্যসংখ্যা বা cross-event rule সম্পর্কে অনুমান করবেন না।

### Germany-র student কি বাংলাদেশে থাকা বন্ধুর সঙ্গে একই team করতে পারবেন?

এটি দুইজনের event affiliation ও current-year team rules-এর ওপর নির্ভর করে। **২০২৬ FAQ অনুযায়ী, team member-দের একই Local Event অথবা একই Universal Event-এর সঙ্গে যুক্ত থাকতে হতো।** Germany-র Local Event-এ থাকা একজন এবং অন্য দেশের participant একই eligible team-এ থাকতে পারবেন—এমন ধরে নেবেন না; event registration করার আগেই current FAQ/Terms বা official support থেকে নিশ্চিত করুন।

### Germany-র Local Event-এ যাতায়াত বা venue সম্পর্কে কোথায় জানব?

Current-year official event page ও Local Lead-এর নির্দেশনা দেখুন। Public transport, accessibility, check-in এবং ফেরার পরিকল্পনা নিজে current local source-এ যাচাই করুন।

### কোনো organizer password বা verification code চাইলে দেব?

না। Password, one-time code, recovery code বা API secret কাউকে দেবেন না। Official support-এর প্রয়োজন হলে নিরাপদ channel-এ error details দিন; credential নয়।

## ১৩. অংশগ্রহণের আগে এবং event-day checklist

### Event-এর আগে

- [ ] Current-year official event ও Participant FAQs দেখেছি।
- [ ] Germany-তে Local Event আছে কি না official listing-এ যাচাই করেছি; না থাকলে অনুমোদিত বিকল্প দেখেছি।
- [ ] Registration confirmation ও event affiliation account-এ মিলিয়েছি।
- [ ] Team eligibility, size, member/event affiliation ও challenge limit current rules-এ যাচাই করেছি।
- [ ] Official start/end/deadline-কে `Europe/Berlin`-এ রূপান্তর করে দ্বিতীয়বার যাচাই করেছি।
- [ ] Summer-time/CET-CEST পরিবর্তনের সম্ভাবনা event date অনুযায়ী পরীক্ষা করেছি।
- [ ] Internet, device, power, API access এবং required software পরীক্ষা করেছি।
- [ ] Communication channel, task owner, backup ও handoff format ঠিক করেছি।
- [ ] Data access, citation, licence, privacy ও AI/SI disclosure requirement বুঝেছি।
- [ ] Local Event onsite হলে venue, check-in, accessibility, travel ও organizer instruction নিশ্চিত করেছি।

### Event চলাকালীন

- [ ] Challenge work কেবল official অনুমোদিত window-তে শুরু করেছি।
- [ ] Must-have scope ও feature cutoff লিখেছি।
- [ ] Source/decision/limitation নথিবদ্ধ করেছি।
- [ ] বিরতি, পানি, খাবার ও বিশ্রামের সময় রেখেছি।
- [ ] Demo ও submission-এর technical fallback প্রস্তুত করেছি।
- [ ] Reviewer-এর জন্য link access এবং final submission status পরীক্ষা করেছি।
- [ ] কোনো key, password বা ব্যক্তিগত তথ্য public file/screenshot-এ নেই।
