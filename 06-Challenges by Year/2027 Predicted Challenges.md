# ৩. ২০২৭-এর জন্য বিস্তারিত কল্পিত Challenge-প্রস্তাব

## Proposal 1 — Earth’s Early-Warning Atlas

**সহজ বাংলা ভাবার্থ:** পৃথিবীর বহু-ঝুঁকির আগাম সংকেতের atlas  
**সম্ভাব্য ক্ষেত্র:** Earth observation, climate adaptation, disaster preparedness, GIS  
**পূর্বাভাস confidence:** উচ্চ  
**আগের বছরের সূত্র:** ২০২৪-এর Landsat, connected Earth, greenhouse gases ও climate story; ২০২৫-এর Terra, healthy cities, SAR, air quality ও weather app; ২০২৬-এর Earth trend ও MODIS/VIIRS fire hotspot।

### কেন এই বিষয় ২০২৭-এ ফিরতে পারে?

তিন বছর ধরে পৃথিবী পর্যবেক্ষণ ও পরিবেশগত পরিবর্তন challenge-গুলোর বড় অংশ। ২০২৪-এ Earth-system সম্পর্ক, জলবায়ু ও community mapping; ২০২৫-এ satellite data-ভিত্তিক city/air/weather problem; ২০২৬-এ trend ও fire record harmonization এসেছে। পরবর্তী edition-এ একাধিক বিপদ/পরিবেশগত stress একসঙ্গে দেখানোর tool একটি সম্ভাব্য নতুন রূপ।

### কল্পিত problem statement

> “NASA ও অন্যান্য উন্মুক্ত Earth-observation data ব্যবহার করে একটি নির্দিষ্ট অঞ্চলে একাধিক পরিবেশগত ঝুঁকির সময়, স্থান ও সম্ভাব্য প্রভাব একত্রে দেখানো এমন একটি tool তৈরি করুন, যা community, planner বা responder-কে প্রস্তুতির অগ্রাধিকার নির্ধারণে সাহায্য করবে।”

এটি কল্পিত wording—official brief নয়।

### সম্ভাব্য ঝুঁকি

- বন্যা/জলাবদ্ধতা;
- তাপপ্রবাহ;
- খরা;
- বন-আগুন বা smoke;
- coastal flooding/erosion;
- দূষণ বা পানির চাপ।

সব ঝুঁকি এক tool-এ নেওয়া দরকার নেই। Hackathon-এ একটি অঞ্চল ও ১–২টি hazard নিলে কাজ manageable হয়।

### সম্ভাব্য deliverable

- interactive risk map;
- সময়ভিত্তিক hazard calendar;
- historical event comparison;
- vulnerable infrastructure/community layer;
- preparedness checklist বা alert mock-up;
- data-driven explanatory story।

### সম্ভাব্য workflow

1. নির্দিষ্ট community/অঞ্চল বেছে নিন।
2. প্রধান hazard ও target user ঠিক করুন।
3. relevant satellite, climate, weather ও local data inventory তৈরি করুন।
4. data scale, observation date, quality flag ও missing data পরীক্ষা করুন।
5. hazard indicator-কে map/time-series-এ দেখান।
6. exposure বা vulnerability layer থাকলে তার source ও privacy বিবেচনা করুন।
7. map থেকে কী সিদ্ধান্ত নেওয়া যায়, কী যায় না—দেখান।

### সতর্কতা

- historical risk map মানেই নিশ্চিত ভবিষ্যৎ পূর্বাভাস নয়।
- একাধিক hazard-এর score যোগ করলে weighting প্রকাশ করতে হবে।
- coarse satellite data দিয়ে বাড়ি/ব্যক্তি-স্তরের নিশ্চয়তা দেবেন না।
- emergency alert-এর ক্ষেত্রে সরকারি আবহাওয়া/দুর্যোগ সংস্থার তথ্যই অগ্রাধিকার পাবে।
- vulnerable group-কে মানচিত্রে দেখানোর সময় privacy ও stigmatization এড়ান।

## Proposal 2 — Farm Futures: Water, Soil and Crop Decisions

**সহজ বাংলা ভাবার্থ:** কৃষির ভবিষ্যৎ—পানি, মাটি ও ফসলের সিদ্ধান্ত  
**সম্ভাব্য ক্ষেত্র:** sustainable agriculture, crop planning, Earth observation, climate resilience  
**পূর্বাভাস confidence:** উচ্চ  
**আগের বছরের সূত্র:** ২০২৪-এর কৃষি-সিদ্ধান্ত tool; ২০২৫-এর NASA Farm Navigators game; ২০২৬-এর Field Shift crop-rotation decision support।

### কেন পুনরাবৃত্তির সম্ভাবনা বেশি?

কৃষি ২০২৪, ২০২৫ ও ২০২৬—তিন edition-এই সরাসরি এসেছে: satellite data দিয়ে কৃষককে সাহায্য, কৃষি-শিক্ষামূলক simulation এবং crop rotation/soil health। ২০২৭-এ একই বিষয় নতুন data, অঞ্চলের পার্থক্য বা farmer-centered tool হিসেবে ফিরতে পারে।

### কল্পিত problem statement

> “NASA Earth observations, স্থানীয় মাটি ও কৃষকের লক্ষ্য ব্যবহার করে এমন সিদ্ধান্ত-সহায়ক অভিজ্ঞতা তৈরি করুন, যা পানি, ফসলের বৈচিত্র্য, মাটির স্বাস্থ্য ও changing climate-এর মধ্যে কৃষি-পরিকল্পনা তুলনা করতে সাহায্য করে।”

### সম্ভাব্য প্রকল্পের দিক

- সেচ ও বৃষ্টির সময়সূচি নিয়ে scenario;
- crop rotation তুলনা;
- খরা/অতিরিক্ত বৃষ্টির জন্য farm planning;
- মাটির অবস্থা ও satellite vegetation signal একসঙ্গে দেখা;
- farmer education game;
- স্থানীয় কৃষি-পরামর্শকের dashboard।

### সম্ভাব্য input

- স্থান/field boundary;
- crop type ও season;
- soil type/soil measurement;
- irrigation availability;
- precipitation/temperature/vegetation data;
- user priority: yield, water saving, soil cover, risk reduction।

### সম্ভাব্য output

- alternative rotation sequence;
- soil/water indicator-এর qualitative comparison;
- trade-off chart;
- input assumptions ও data source;
- farmer preference অনুযায়ী ranking;
- uncertainty/region coverage note।

### কাজের ধাপ

1. কোন সিদ্ধান্তে সহায়তা করতে চান তা নির্দিষ্ট করুন।
2. NASA data এবং local soil/crop data-এর ভূমিকা আলাদা করুন।
3. এক বা দুইটি crop/region দিয়ে prototype শুরু করুন।
4. option তুলনার scoring rule প্রকাশ করুন।
5. সম্ভাব্য ব্যবহারকারী/কৃষি-জ্ঞানসম্পন্ন ব্যক্তির feedback নিন।
6. ফলকে measured yield বা guaranteed advice বলে উপস্থাপন করবেন না।

### সতর্কতা

- satellite data field-এর সব মাটির বৈশিষ্ট্য বলে না।
- একই crop strategy সব অঞ্চল বা কৃষকের জন্য উপযুক্ত নয়।
- বাজার, জমির মালিকানা, শ্রম, বীজ, সেচ ও ঋণের বাস্তবতা বিবেচ্য।
- advice tool-কে কৃষিবিদ বা স্থানীয় extension service-এর বিকল্প করবেন না।

## Proposal 4 — Decode the Changing Earth

### সম্ভাব্য analytical capability

- trend slope;
- seasonality decomposition;
- region-to-region comparison;
- confidence band;
- outlier/event marker;
- variable metadata catalog;
- observed বনাম model-generated series আলাদা করা।

### সতর্কতা

### সম্ভাব্য সমস্যা

বিশাল আকাশ-সমীক্ষা থেকে বহু image ও observation তৈরি হয়। সময়ের সঙ্গে অবস্থান বা উজ্জ্বলতা বদলানো asteroid, comet, variable star, transient বা exoplanet signal শনাক্ত করতে মানুষকে বড় ডেটা ঘাঁটতে হয়।

### কল্পিত problem statement

> “উন্মুক্ত space-survey image বা time-series ব্যবহার করে পরিবর্তনশীল/চলমান astronomical candidate খুঁজে, user-কে evidence ও confidence দেখানো একটি accessible analysis tool তৈরি করুন।”

### সম্ভাব্য detection path

- multi-epoch image difference;
- source brightness time-series;
- transit-like dip;
- moving object candidate;
- anomaly ranking;
- human review queue।

### সম্ভাব্য feature

- image blink/slider;
- candidate list with confidence;
- source coordinates ও observation date;

5. precision/recall, false positive ও false negative দেখান।
6. sample candidate-কে original source-এ trace করুন।

### সতর্কতা

- AI candidate detection নিশ্চিত আবিষ্কার নয়।
- image artifact, alignment error, cosmic ray বা detector issue false positive তৈরি করতে পারে।
- training/test leakage model-এর performance ভুলভাবে বাড়াতে পারে।
- public user candidate scientific confirmation নয়।

# ৭. সংক্ষিপ্ত শব্দের অভিধান

| শব্দ | সহজ ব্যাখ্যা |
|---|---|
| **Earth System** | বায়ুমণ্ডল, জল, ভূমি, বরফ ও জীবজগতের পারস্পরিক সংযুক্ত ব্যবস্থা |
| **Trend** | সময়ের সঙ্গে কোনো variable-এর পরিবর্তনের ধারা |
| **Statistical significance** | নির্দিষ্ট statistical test ও assumptions অনুযায়ী পরিবর্তন chance দিয়ে ব্যাখ্যা করা কতটা অসঙ্গত |
| **Life support** | মানুষের বেঁচে থাকার জন্য বাতাস, পানি, তাপমাত্রা ইত্যাদি নিয়ন্ত্রণ |
| **Radiation shielding** | বিকিরণ থেকে crew/equipment-কে রক্ষার উপকরণ বা ব্যবস্থা |
| **SAR** | Synthetic Aperture Radar; radar signal ব্যবহার করে পৃষ্ঠ পর্যবেক্ষণ |
| **NISAR** | NASA-ISRO Synthetic Aperture Radar mission |
| **Crop rotation** | একই জমিতে বিভিন্ন সময়ে/মৌসুমে পরিকল্পিত ফসল পরিবর্তন করে চাষ |
| **Microgravity** | কক্ষপথে মুক্ত-পতনের কারণে কার্যকরভাবে কম মাধ্যাকর্ষণ অনুভূত হওয়ার পরিবেশ |
| **Combustion** | জ্বালানি ও oxidizer-এর রাসায়নিক বিক্রিয়ায় তাপ/আলো উৎপন্ন হওয়া |
| **MODIS** | NASA-র Moderate Resolution Imaging Spectroradiometer instrument |
| **VIIRS** | Visible Infrared Imaging Radiometer Suite satellite instrument |
| **Hot spot** | satellite fire product-এ active burning-এর সম্ভাব্য pixel/স্থান |
| **Terrestrial analog** | অন্য গ্রহ/উপগ্রহের নির্দিষ্ট বৈশিষ্ট্যের সঙ্গে তুলনার জন্য ব্যবহৃত পৃথিবীর স্থান |
| **Marswalk** | মঙ্গলের পৃষ্ঠে astronaut-এর বাইরে গিয়ে কাজ/অনুসন্ধান |
| **Line of sight** | দুই অবস্থানের মধ্যে বাধাহীন সরল দৃষ্টিপথ/যোগাযোগের পথ |
| **SPHEREx** | আকাশের near-infrared survey করা NASA mission |
| **Time-domain astronomy** | সময়ের সঙ্গে astronomical source-এর পরিবর্তন বিশ্লেষণ |
| **Sonification** | data-কে sound-এর বৈশিষ্ট্যে রূপান্তর করে শোনানো |
| **Decision support** | ব্যবহারকারীকে বিকল্প তুলতে সাহায্যকারী ব্যবস্থা; নিজে চূড়ান্ত সিদ্ধান্ত নয় |
| **Harmonization** | ভিন্ন উৎস/সেন্সরের data তুলনাযোগ্য করার প্রক্রিয়া |
| **Uncertainty** | মাপ বা model result কতটা অনিশ্চিত তার পরিমাণ/বর্ণনা |
| **False positive** | বাস্তবে ঘটনা নেই, তবু model আছে বলে চিহ্নিত করেছে |
| **False negative** | বাস্তবে ঘটনা আছে, কিন্তু model শনাক্ত করতে পারেনি |
| **Data leakage** | test/validation-এর তথ্য training-এ ঢুকে ফলকে কৃত্রিমভাবে ভালো দেখানো |
| **Prototype** | ধারণা ও মূল user flow যাচাইয়ের প্রাথমিক কার্যকর সংস্করণ |
| **Data provenance** | data কোথা থেকে এসেছে ও কীভাবে বদলেছে তার ইতিহাস |
